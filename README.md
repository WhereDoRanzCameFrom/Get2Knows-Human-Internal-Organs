# Human Internal Organs

An educational application designed to help users learn about human internal organs, including the heart, brain, stomach, and lungs. This application provides a simple and interactive way to explore the basic functions of each organ.

## 🧠 About The Project

**Human Internal Organs** is a simple educational application developed using Unity. It aims to introduce users to four major human internal organs through visual presentations and informational content.

The application is designed to make learning about human anatomy more accessible, engaging, and enjoyable.

## 🫀 Organs Covered

This application introduces four main human internal organs:

- **Heart** – Learn about the heart and its role in pumping blood throughout the body.
- **Brain** – Discover the brain and its function in controlling body activities.
- **Stomach** – Explore the stomach and its role in the digestive process.
- **Lungs** – Learn about the lungs and their function in breathing and gas exchange.
